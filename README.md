inferx sizing tool

can size gpu compute based on inferx in house management stack, validated storage architecture, and validated gpu compute nodes.

can perform workload based performance estimates for gpuaas environments.

all data is scrabed from spec.org benchmarks, open-gpulib, nvidia reference documentation, weka technical material and sizing documentation, and others.

it has proved to reliably estimate performance, based on real sizings and performance estimates, however all exports need to be checked by the user before sending. 

it can also export a bom, network stuff, and the datasheet.
